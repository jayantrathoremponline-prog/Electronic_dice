#Electronic Dice

The Electronic Dice is a digital dice circuit designed and developed using KiCad. The project uses a CD4017 decade counter to generate sequential outputs, which are displayed through seven LEDs arranged in a dice pattern.

A 555 timer is used to generate clock pulses for the CD4017. Diodes are used to control the LED combinations so that the circuit displays the numbers 1 to 6 like a conventional dice. Push buttons are provided for controlling the operation, while resistors limit the LED current and capacitors provide timing and filtering.

The complete project includes the schematic, PCB layout, copper layers, and 3D PCB design. The PCB was designed as a compact single-board electronic dice, with clearly arranged components and labeled LED positions.

Main Components: NE555 timer IC, CD4017 counter IC, 7 LEDs, 12 × 1N4148 diodes, resistors, capacitors, and push buttons.
